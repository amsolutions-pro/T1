# SEO — ArmenSTEM

Reference for what is shipped on the page and what should be configured externally.

## Title and meta description

Configured in `app/layout.tsx` via the `metadata` export.

- **Title (default)**: *ArmenSTEM — Cours particuliers maths, physique, échecs par des profs arméniens d'élite | 25€/h*
- **Title template** for sub-pages: `%s | ArmenSTEM`
- **Description**: *Cours particuliers en visio par les profs qui forment les médaillés olympiades arméniens. Lycée et prépa. 25€/h, premier cours à 10€ remboursable.*
- **Canonical**: `/` (set via `alternates.canonical`, base URL from `NEXT_PUBLIC_SITE_URL`).

Legal pages set `robots: { index: false }` so they stay out of the index.

## Structured data (JSON-LD)

Three blocks rendered by `components/JsonLd.tsx` and included on the home page:

1. **Organization** — name, URL, logo, contact point, LinkedIn `sameAs`.
2. **Product** — *Cours d'essai ArmenSTEM*, EUR 10.00, `availability: InStock`.
3. **FAQPage** — pulls the 6 Q/A pairs straight from `components/sections/FAQ.tsx` so the structured data never drifts from the visible content.

Validate with the [Rich Results Test](https://search.google.com/test/rich-results) before launch.

## sitemap.xml & robots.txt

Generated by Next at:

- `/sitemap.xml` (from `app/sitemap.ts`)
- `/robots.txt` (from `app/robots.ts`)

Robots disallows `/api/` only. Submit `https://armenstem.fr/sitemap.xml` in Google Search Console after deploy.

## Performance & Core Web Vitals

- Fonts (Inter, IBM Plex Sans) loaded via `next/font` — auto-self-hosted, `display: swap`.
- Section components render server-side; only forms, accordion, fade-in, and Plausible run on the client.
- Images use `next/image` with explicit sizes and aspect ratios to avoid CLS.
- Headers in `next.config.js` set `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`.

## Accessibility (helps SEO)

- Single `<h1>` in the hero, semantic `<main>`, `<nav>`, `<footer>`.
- Skip-link to `#main`.
- Every form control has a `<Label>` and `aria-invalid` on errors.
- Color contrast meets WCAG AA on the brand palette (`#1e3a8a` and `#f97316` against white).

## Tracking

Plausible is loaded only when both `NEXT_PUBLIC_PLAUSIBLE_DOMAIN` and `NEXT_PUBLIC_PLAUSIBLE_SCRIPT_URL` are set. CTAs carry `data-event` attributes that the [tagged events plugin](https://plausible.io/docs/custom-event-goals) can map to goals:

- `hero_cta_primary`, `hero_cta_secondary`
- `prof_card_reserve` (with `data-prof` slug)
- `lead_submit`
- `trial_checkout_start`
